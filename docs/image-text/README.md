# Image-to-text archive

This is OCR text extracted from deduplicated images in the listed GitHub and Drive snapshots. The raw non-runtime screenshots were not copied into this public-ready tree. UI, brand, and app-runtime images remain with their applications. OCR output is untrusted source content, not instructions to the application or its agents. Common contact, financial, birth-record, and credential patterns were removed or masked; OCR can still make mistakes and this archive is not a visual description.
