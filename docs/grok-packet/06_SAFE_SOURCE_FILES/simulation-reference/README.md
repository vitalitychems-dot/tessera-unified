# Simulation-provider reference excerpt

Only the provider adapter and its controlled simulation contract test are included. They are reference material, not a runnable service. The router, orchestration, persistence layer, knowledge store, automation modules, credentials/configuration, database, and service deployment files are intentionally absent.

Do not add a storefront connection or accept customer, account, order, checkout, payment, session, or visitor-derived aggregate data. The adapter's input screening is not a guarantee that arbitrary prompts are free of sensitive material.
