# Static storefront references

This folder contains selected public product/brand imagery and a static vial-image map only. It is not a runnable storefront. It has no customer records, transactions, checkout, payment, account, visitor analytics, or service connection.

WebP product images are included in the main handoff; their PNG originals are supplied in `grok-handoff-images.zip` at the same relative paths. Extract both archives into the same folder to reconstruct the full static image directory. Image metadata is stripped from copied user-provided brand images; no certificates of analysis or administrative/customer screenshots are included.
